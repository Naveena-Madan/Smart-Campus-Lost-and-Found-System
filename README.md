# Smart Campus Lost and Found System

## Project Description
The Smart Campus Lost and Found System is a Java-based desktop application developed to help students and administrators report, search, manage, and recover lost and found items within a campus.

The system provides a centralized platform for reporting lost and found belongings, identifying potential matches, submitting claims, and verifying item ownership.

## Technologies Used
- Java
- Java Swing
- Object-Oriented Programming (OOP)
- MySQL
- JDBC
- Multithreading

## Main Features
- Student and Administrator Login
- Student and Administrator Dashboards
- Lost Item Reporting
- Found Item Reporting
- Image Upload
- Smart Matching with Match Score Calculation
- Item Claim Processing
- Ownership Verification
- Administrator Claim Approval and Rejection
- Notifications
- AI Assistant
- Profile and Settings Management

## Project Structure
- `src/gui` – Graphical user interface classes
- `src/model` – Data model classes
- `src/service` – Application logic and services
- `src/database` – Database configuration
- `src/exception` – Custom exception classes
- `database` – SQL database scripts
- `screenshots` – Application screenshots
- `lib` – Required external libraries

## Requirements
- Java Development Kit (JDK)
- IntelliJ IDEA or another Java IDE
- MySQL Server
- MySQL Connector/J

## Setup and Execution
1. Install the JDK and MySQL Server.
2. Create the project database in MySQL.
3. Import the SQL script provided in the `database` folder.
4. Configure the database connection using the environment variable `LOST_FOUND_DB_PASSWORD`.
5. Add MySQL Connector/J to the project's libraries.
6. Open the project in IntelliJ IDEA.
7. Configure the required environment variable in the run configuration.
8. Run the main application class to launch the system.
